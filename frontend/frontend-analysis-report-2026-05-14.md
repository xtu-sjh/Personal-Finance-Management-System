## 🔴 严重问题（P0）

> 影响系统可用性、安全性或导致功能完全失效

### 1. 文件结构混乱 - 存在两套重复HTML

**问题描述**：项目中存在新旧两套HTML文件，功能重复且维护困难

| 旧版文件 | 新版文件 | 说明 |
|----------|----------|------|
| `01-index.html` | `login.html` | 登录页重复 |
| `02-register.html` | `register.html` | 注册页重复 |
| `03-dashboard.html` | `dashboard.html` | 仪表盘重复 |
| `04-records.html` | `records.html` | 记账页重复 |
| ❌ `05-statistics.html` | `statistics.html` | 旧版不存在 |
| ❌ `06-budget.html` | `budget.html` | 旧版不存在 |

**影响**：
- 维护成本翻倍
- 用户可能访问到错误版本
- 代码库臃肿

**建议**：删除所有 `0X-*.html` 文件，仅保留新版

---

### 2. 旧版HTML引用不存在的JS文件

**问题描述**：旧版页面引用了从未创建的JavaScript文件

| 文件 | 引用的JS | 状态 |
|------|----------|------|
| `01-index.html` | `js/07-axios-config.js` | ❌ 不存在 |
| | `js/01-login.js` | ❌ 不存在 |
| `02-register.html` | `js/07-axios-config.js` | ❌ 不存在 |
| | `js/02-register.js` | ❌ 不存在 |
| `04-records.html` | `js/07-axios-config.js` | ❌ 不存在 |
| | `js/utils.js` | ❌ 不存在 |

**影响**：这些页面打开后控制台报错，功能完全不可用

**建议**：删除旧版文件，或补充缺失的JS文件

---

### 3. 旧版导航链接指向不存在的页面

**问题描述**：`03-dashboard.html` 中的链接指向不存在的页面

```html
<a href="05-statistics.html">统计分析</a>  <!-- 文件不存在 -->
<a href="06-budget.html">预算管理</a>      <!-- 文件不存在 -->
```

**影响**：用户点击后显示404错误

**建议**：删除旧版文件，统一使用新版导航

---

### 4. XSS安全漏洞

**问题描述**：`04-records.html` 中存在跨站脚本攻击漏洞

```javascript
// 第80-81行 - 直接拼接用户数据到HTML
html += `<tr><td>${type}</td><td>${item.category}</td><td>${item.money}</td>...`;
```

**影响**：攻击者可通过注入恶意脚本窃取用户数据

**对比**：新版 `records.js` 已使用 `escapeHtml()` 转义

**建议**：删除旧版文件，或对所有动态内容进行HTML转义

---

### 5. 记录编辑功能缺失

**问题描述**：收支记录只能删除，无法修改

**用户痛点**：
- 记错金额时只能删除重录
- 分类选错无法修改
- 日期错误无法纠正

**API支持**：后端已提供 `PUT /api/records/{id}` 接口

**建议**：添加编辑弹窗，支持修改类型、分类、金额、日期、备注

---

### 6. 无分页机制 - 数据量大时性能崩溃

**问题描述**：记录列表一次性加载全部数据

**代码证据**：
```javascript
// records.js - 限制200条但无分页UI
var pageData = await api.get('/api/records', { params: { userId: currentUser.id } });
```

**影响**：
- 记录超过200条时显示不全
- 页面加载缓慢
- 无法快速定位历史记录

**API支持**：后端支持 `page` 和 `size` 参数

**建议**：实现分页组件，支持每页条数选择

## 🟠 重要问题（P1）

> 影响用户体验或功能完整性

### 7. login.js 元素ID不匹配

**问题描述**：`login.js` 引用的元素ID与 `01-index.html` 不一致

```javascript
// login.js
const alert = document.getElementById('alert');     // 01-index.html 中是 'errorMsg'
const btn = document.getElementById('loginBtn');    // 01-index.html 中无此ID
```

**影响**：访问旧版登录页时JavaScript报错

**建议**：统一元素ID或删除旧版文件

---

### 8. API接口路径不一致

**问题描述**：新旧版本使用不同的API路径和数据格式

| 功能 | 旧版 | 新版 |
|------|------|------|
| 获取记录 | `/api/record/list` | `/api/records` |
| 记录类型值 | `0`/`1` | `'expense'`/`'income'` |
| 金额字段 | `item.money` | `item.amount` |

**影响**：后端只能适配一套，另一套必然报错

**建议**：统一API规范，删除不兼容版本

---

### 9. 记录搜索筛选功能缺失

**问题描述**：记录列表无搜索、筛选、排序功能

**用户痛点**：
- 想找某笔交易只能逐页翻
- 无法按金额范围筛选
- 无法按分类筛选
- 无法按日期范围筛选
- 无法排序

**建议**：添加筛选工具栏
- 按月份选择
- 按分类下拉筛选
- 按金额范围输入
- 按日期范围选择
- 表头点击排序

---

### 10. 自定义分类功能缺失

**问题描述**：收入/支出分类硬编码，用户无法自定义

```javascript
// records.html - 固定7个分类
<select id="category">
  <option>餐饮</option><option>交通</option><option>购物</option><option>娱乐</option>
  <option>工资</option><option>奖金</option><option>兼职</option>
</select>
```

**用户痛点**：
- 无法添加个人专属分类（医疗、教育、宠物等）
- 分类不贴合实际消费场景

**建议**：
- 添加分类管理页面
- 支持增删改自定义分类
- 区分收入/支出分类

---

### 11. 数据导出功能缺失

**问题描述**：数据只能在系统内查看，无法导出

**用户痛点**：
- 无法生成报表给财务顾问
- 无法备份数据
- 无法进行外部数据分析

**建议**：支持导出为
- Excel (.xlsx)
- CSV (.csv)
- PDF 报表

---

### 12. 提示方式过于粗暴

**问题描述**：大量使用原生 `alert()` 和 `confirm()`

**代码证据**：
```javascript
// 多处使用
alert('添加成功！');
alert('加载失败');
if (!confirm('确定删除？')) return;
```

**影响**：
- 阻断用户操作流
- 视觉风格不统一
- 移动端体验差

**建议**：替换为非阻断式Toast通知 + 自定义确认弹窗

---

### 13. 预算功能过于单薄

**问题描述**：只有"总预算"，无分类预算

**现状**：
```javascript
// budget.js - 只设置总预算
await api.post('/api/budget', {
  userId: currentUser.id,
  category: '总预算',  // 固定为总预算
  amount: monthMoney,
  month: currentMonth
});
```

**用户痛点**：
- 无法控制单项支出（餐饮2000、娱乐500）
- 无法知道哪项超支

**建议**：
- 支持按分类设置预算
- 预算预警通知（接近/超支提醒）
- 历史预算对比分析

---

### 14. 账户管理功能缺失

**问题描述**：无个人中心页面

**缺失功能**：
- 修改密码
- 编辑个人资料（邮箱等）
- 账号注销
- 登录历史查看

**建议**：添加个人中心页面

---

### 15. 忘记密码无法找回

**问题描述**：登录页无"忘记密码"入口

**用户痛点**：密码丢失只能重新注册，数据丢失

**建议**：添加邮箱验证重置密码流程

## 🟡 一般问题（P2）

> 影响代码质量或部分用户体验

### 16. 新旧CSS类名混用

**问题描述**：样式定义存在两套类名

| 元素 | 旧版类名 | 新版类名 |
|------|----------|----------|
| 表单项 | `.form-group` | `.form-item` |
| 错误提示 | `.error` | `.alert` |
| 全宽按钮 | `.btn-block` | `style="width:100%"` |

**影响**：样式可能不一致，维护困难

**建议**：统一使用新版类名，废弃旧版

---

### 17. 页面布局风格不一致

**问题描述**：登录页存在两种布局方式

| 版本 | 布局结构 |
|------|----------|
| 新版 | `.container > .card` |
| 旧版 | `.auth-page > .auth-container > .auth-card` |

**建议**：统一布局结构

---

### 18. CDN版本不一致

**问题描述**：Axios引用方式不统一

```html
<!-- 新版 - 锁定版本 -->
<script src="https://cdn.jsdelivr.net/npm/axios@1.6.7/dist/axios.min.js"></script>

<!-- 旧版 - 无版本号 -->
<script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
```

**影响**：未来可能加载不同版本，导致兼容性问题

**建议**：统一使用锁定版本

---

### 19. 缺少viewport meta标签

**问题描述**：部分页面缺少移动端适配标签

**缺失页面**：
- `01-index.html`
- `02-register.html`

```html
<!-- 缺少这行 -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

**影响**：移动端显示异常，字体过小

**建议**：所有页面添加viewport标签

---

### 20. 表单验证薄弱

**问题描述**：仅检查"必填"，无格式/范围校验

**现状**：
```javascript
// records.js - 只检查非空
if (!money || !createTime) { alert('请填写完整'); return; }
```

**建议**：
- 金额：正数、小数位限制（最多2位）
- 日期：不能选未来日期
- 实时校验 + 行内错误提示

---

### 21. 无加载状态指示

**问题描述**：数据加载时无loading指示

**影响**：
- 用户不知道是加载中还是无数据
- 可能重复点击提交按钮

**建议**：
- 添加loading spinner
- 按钮提交时显示"加载中..."
- 禁用重复提交

---

### 22. 错误处理不友好

**问题描述**：多处catch块静默失败或简单alert

```javascript
// budget.js - 静默失败
} catch (err) {
  // 静默处理
}

// records.js - 简单alert
} catch (e) { alert('加载失败'); }
```

**建议**：
- 统一错误处理机制
- 显示用户友好的错误信息
- 提供重试选项

---

### 23. 记录列表无备注字段

**问题描述**：表单无备注输入，无法记录详细信息

**用户痛点**：
- 无法记录消费场景（如"和朋友聚餐"）
- 无法添加备注说明

**建议**：添加可选的备注输入框

---

## 🟢 优化建议（P3）

> 提升用户体验的锦上添花功能

### 24. 无快捷记账方式

**问题描述**：每笔记录都要手动填写全部字段

**建议**：
- 记账模板功能（保存常用记录）
- 常用记录快速复制
- 周期性记录自动创建（如每月房租）

---

### 25. 无深色模式

**问题描述**：只有浅色主题，长时间使用伤眼

**建议**：添加主题切换功能
- 跟随系统设置
- 手动切换
- 记住用户偏好

---

### 26. 统计维度不足

**问题描述**：仅有饼图和折线图

**建议**：
- 收支对比柱状图
- 年度汇总视图
- 同比/环比分析
- 消费趋势预测
- 自定义时间范围统计

---

### 27. 无键盘快捷键

**问题描述**：高频用户效率低

**建议**：添加常用快捷键
- `N` = 新建记录
- `S` = 打开搜索
- `Esc` = 关闭弹窗

---

### 28. 移动端体验待优化

**问题描述**：部分页面响应式不完善

**建议**：
- 移动端导航汉堡菜单
- 表格横向滚动
- 触摸友好的按钮尺寸
- 底部固定操作栏

---

### 29. 无数据安全机制

**问题描述**：用户信息存储在sessionStorage，无过期机制

**现状**：
```javascript
// axios-config.js
sessionStorage.setItem(CURRENT_USER_KEY, JSON.stringify(user));
```

**建议**：
- Token过期自动登出
- 长时间不操作提醒
- 敏感操作二次确认

---

### 30. 无离线支持

**问题描述**：无网络时完全不可用

**建议**：
- Service Worker缓存
- 离线时显示缓存数据
- 联网后自动同步

---

### 31. 无数据备份恢复

**问题描述**：无法备份和恢复数据

**建议**：
- 导出完整数据备份包
- 导入备份恢复数据
- 定期自动备份提醒
